# Equilibria Beauty — desarrollo

Repositorio público: https://github.com/Drakeneess/equilibria-beauty

## Clonar e iniciar

```powershell
git clone https://github.com/Drakeneess/equilibria-beauty.git
cd equilibria-beauty
npm install
npm run dev
```

Abre http://localhost:3000.

## Trabajar sobre main

```powershell
git pull origin main
# realiza tus cambios
git add .
git commit -m "feat: describe los cambios"
git push origin main
```

El formulario actual es una demostración y no procesa reservas reales.
